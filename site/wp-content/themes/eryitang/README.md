# 尔意堂 WordPress 区块主题

当前状态：候选发布前同步阶段。

本主题以 `demo-文案精修-v2/` 和项目固化文档为视觉、结构与交互基线；正式上线使用 WordPress 主题与 `eryitang-core` 功能插件，不直接发布静态页面目录。

## 已完成

- 建立全站设计令牌、公共页头、页脚和移动导航。
- 完成首页、品牌介绍、联系我们、文章列表、文章详情和 404 模板骨架。
- 将首页、品牌页和联系页主要区域拆分为可维护的模板部件。
- 接入首页 Banner、医师、资讯、资质荣誉、联系信息、地图、文章归档、推荐文章、广告、相关资讯和上下篇动态组件。
- 已具备五位医师首页展示与链接、八项疗法链接、调理方向入口和合作咨询入口所需输出能力。
- 使用临时数据完成基础桌面端、手机端、动态和空状态验证；正式上线不得保留占位资料。

## 候选发布前仍需同步

## 维护原则

- 不修改 WordPress 核心文件。
- 内容、人员、图片、链接和广告不硬编码进主题；优先使用插件提供的内容模型和后台设置。
- 版式、模块顺序、响应式规则和公共交互由主题统一维护，不在后台逐页复制样式。
- 本地 PHP 8.4/SQLite 与计划生产环境 PHP 8.3/MySQL 8.0 不同，上线前必须完成兼容、迁移和回归验证。
- 生产发布前以 `项目固化文档/QA_CHECKLIST.md` 和项目阶段确认清单为验收依据。
