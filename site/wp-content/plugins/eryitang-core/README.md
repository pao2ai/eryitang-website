# 尔意堂网站功能插件

当前版本：`0.4.4`。基础信息、页面图片、链接与入口后台均已按内容用途拆分为与广告配置相同宽度的独立卡片；文章列表页与详情页右侧“重点推荐”统一最多展示5篇；公共页脚的ICP备案号链接至工信部备案系统，公安备案号在后台填入后会自动生成带警徽图标的官方查询链接。正式站部署与运行验证状态见项目固化文档。

插件负责与主题分离的业务内容、后台字段和动态输出。更换或维护页面样式时，不应丢失已经录入的内容数据。

## 当前能力

- 医师团队内容类型，以及职称、专业方向、执业信息、坐诊时间、排序、首页展示和详情链接字段。
- 资质证书与荣誉锦旗内容类型、资料类型、说明和展示顺序字段。
- 文章重点推荐、首页展示、排序和相关文章字段。
- 医馆名称、电话、地址、营业时间、地图、二维码、联系页图片和备案信息设置。
- 首页 Banner 眉题、标题、副标题、图片和替代文字设置。
- 两个文章侧边广告位的启用、标题、图片、替代文字、链接和打开方式设置。
- 页面底部广告图片及显示状态。
- 首页八项疗法跳转链接和全站合作咨询文字、链接、打开方式设置。
- 首页、品牌、联系、文章列表和文章详情所需动态输出组件。
- 独立一级菜单“页面固定内容”，用于安全替换首页/品牌页模板固定文字和图片、联系页环境轮播、顶部/底部Logo及高级背景素材。
- 固定内容逐字段字数/比例提示、超长文字二次确认、图片比例服务器校验、分区增量保存和上一次内容恢复。
- 全站SEO默认值、页面/文章/分类SEO字段、canonical、Open Graph、Twitter Card、JSON-LD与动态`llms.txt`。

## 上线前内容要求

- 用户确认五位医师可先使用当前补位内容首发、上线后替换；不得添加会被理解为已经核验的虚构执业资质、履历或诊疗效果，正式资料到位后应优先替换。
- 八项疗法、合作咨询、广告和医师卡片的跳转地址必须逐项验证。
- 非遗介绍、资质事实、医疗措辞、案例图片和人员履历必须由项目方最终确认。
- Banner、二维码、联系页图片及广告图片已接入 WordPress 媒体库选择器，并继续保存兼容的 URL 字段。

## 当前生产状态（2026-08-25）

- 正式站已完成文章、医师、资质、Banner、地图、二维码、疗法链接、合作咨询、广告和基础信息的初始配置。
- 页面固定内容首次未保存时使用与正式页面一致的代码默认值，不会因插件升级改写现有WordPress数据或改变前台视觉。
- 固定内容保存后直接作用正式站；普通发布不默认创建服务器恢复点，每个分区只保留一次配置级“上一次内容”。

## 安全与维护原则

- 不依赖付费字段插件。
- 所有输入继续执行权限、Nonce、数据清理和输出转义检查。
- 后续发布继续先做本地PHP/JS校验，再在服务器临时目录以PHP 8.3复核，最后执行正式站390px/1440px回归。
- 后台可配置范围以 `项目管理/WordPress后台可配置内容清单-2026-08-13.md` 为准；版式和全站动效仍由主题统一维护。
