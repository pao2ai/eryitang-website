# 尔意堂官方网站交付后维护清单（客户简版）

**适用网站：** https://www.eytzyg.cn  
**管理责任：** 域名、服务器及 SSL 证书均由客户自行管理  
**使用说明：** 本清单仅用于日常提醒。涉及服务器设置、网站功能、主题、插件、数据库或域名解析的修改，请联系技术人员处理。

## 一、交付后立即完成

- [ ] 登录 WordPress 后台，修改交付时提供的初始管理员密码。
- [ ] 确认 WordPress 管理员账号绑定的是客户自己的常用邮箱。
- [ ] 确认腾讯云账号绑定的手机号、邮箱可以正常接收通知。
- [ ] 确认域名管理账号中的实名认证、手机号和邮箱信息有效。
- [ ] 开启服务器、域名和 SSL 证书的到期提醒；条件允许时开启自动续费。
- [ ] 将各项账号交由固定负责人保管，不在微信群、普通文档或公开位置保存和发送密码。

## 二、常用管理入口

| 管理事项 | 登录入口 | 使用说明 |
| --- | --- | --- |
| WordPress 网站后台 | https://www.eytzyg.cn/wp-admin/ | 使用网站管理员账号登录；首次登录后立即修改初始密码 |
| 腾讯云服务器 | https://cloud.tencent.com/login | 登录腾讯云后，进入“控制台 → 云服务器 → 实例”查看服务器 |
| 域名管理 | 登录域名当前所属服务商的管理后台 | 用于查看域名到期时间、续费状态和联系人信息 |
| SSL 证书管理 | 登录证书当前所属服务商的管理后台 | 用于查看证书到期时间和续签状态 |
| GitHub 正式备份 | https://github.com/pao2ai/eryitang-website | 用于网站故障恢复；不要随意删除仓库、文件或 `main` 分支 |

> 本清单不填写账号、密码、短信验证码、SSH 私钥或支付信息。请使用可靠的密码管理工具单独保管。

## 三、日常维护提醒

### WordPress 后台

- [ ] 管理员初始密码已经修改，并由客户自行保管。
- [ ] 不多人共用同一个管理员账号。
- [ ] 工作人员离职或负责人变更后，及时修改密码或停用其账号。
- [ ] 日常只进行文章发布、图片上传和文字修改等内容维护。
- [ ] 不随意安装、删除或升级主题和插件。
- [ ] 涉及网站结构、功能或大范围内容调整时，先联系技术人员。

### 腾讯云服务器

- [ ] 建议开启自动续费，并确保续费账户或支付方式有效。
- [ ] 收到到期提醒后，直接登录腾讯云官网核实，不通过陌生短信链接付款。
- [ ] 服务器到期前至少 **30 天**完成续费确认。
- [ ] 不随意关机、重装、销毁或更换服务器。
- [ ] 不向无关人员提供腾讯云或服务器登录权限。

### 域名

- [ ] 域名 `eytzyg.cn` 到期前至少 **30 天**完成续费确认。
- [ ] 建议开启自动续费，并确保续费账户或支付方式有效。
- [ ] 保持域名实名认证、联系人手机号和邮箱有效。
- [ ] 不随意修改或删除域名解析记录。
- [ ] 收到域名到期、实名认证或其他异常通知时，及时处理或联系技术人员。

### SSL 证书

- [ ] SSL 证书到期前至少 **30 天**确认续签状态。
- [ ] 建议开启证书到期提醒。
- [ ] 收到证书即将到期或续签失败通知时，及时联系技术人员。
- [ ] 不忽略证书通知；证书过期后，浏览器可能提示网站“不安全”。

## 四、每月一次提醒

建议由指定负责人每月固定检查一次：

- [ ] 网站首页可以正常打开：https://www.eytzyg.cn
- [ ] WordPress 后台可以正常登录。
- [ ] 腾讯云账号可以正常登录。
- [ ] 腾讯云没有服务器欠费或即将到期提醒。
- [ ] 域名没有即将到期或实名认证异常提醒。
- [ ] SSL 证书没有即将到期或续签失败提醒。
- [ ] 客户用于接收通知的手机号和邮箱仍可正常使用。

## 五、年度重点提醒

- [ ] 每年核对一次服务器、域名和 SSL 证书的到期日期。
- [ ] 确认自动续费状态及支付方式仍然有效。
- [ ] 确认腾讯云、域名和网站后台的负责人没有发生遗漏或变更。
- [ ] 检查账号绑定的手机号、邮箱和实名认证信息是否需要更新。

## 六、重要注意事项

1. 服务器、域名或 SSL 证书到期，都可能导致网站无法正常访问。
2. 自动续费不能代替人工确认，应在到期前主动检查续费状态。
3. 收到续费通知时，应直接登录服务商官网核实，谨防诈骗短信和钓鱼链接。
4. 不要随意修改域名解析、服务器设置、WordPress 主题或插件。
5. GitHub 保存的是网站正式交付时的恢复版本。客户后续新增的文章、图片和其他内容不会自动同步到该备份。
6. 网站需要迁移、恢复或进行较大调整时，应联系技术人员操作。
